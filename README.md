# Exercise 16 · First Two Spring Framework Apps

Two standalone Spring Boot projects built with Java 21 and Maven for the Vistula University Spring Framework exercise.

| Project | What it demonstrates |
| --- | --- |
| [Task 1 · firstspringapp](firstspringapp/README.md) | A plain-text HTTP response and a personalized Thymeleaf greeting with the Vistula University logo. |
| [Task 2 · FirstRestAPI](FirstRestAPI/README.md) | Product CRUD, JSON responses, error handling, Spring Data JPA, H2, Swagger UI and Postman. |

Each project guide includes setup instructions, screenshots and steps to reproduce the demo. Both applications default to port 8080. The Task 2 guide shows how to run the API on port 8081 while Task 1 is running.
